# 01 · 快速开始

目标：手机上跑起 dsh 网页/命令行界面，并能被脚本一句话调用。

---

## 0. 前提

- Android **arm64**，Termux（**F-Droid / GitHub 版**；Google Play 版包名不同、缺 `pkg` 权限）
- 存储 ≥ 2 GB 空闲，Wi-Fi
- 一个 OpenAI 兼容端点（`/v1/chat/completions`）与 API Key

---

## 1. 装基础环境

```bash
pkg update -y
pkg install -y nodejs python git openssh tmux termux-api android-tools curl
node -v && python -V
```

建议顺手装 **Termux:Boot**（开机自启用）和 **Termux:API**（剪贴板/通知等，可选）。

---

## 2. 装 dsh-termux

```bash
# 方式 A：上游预编译包
npm i -g ./dsh-termux.tgz

# 方式 B：从 npm 源（如已发布）
npm i -g dsh-termux

command -v dsh && dsh --version
```

装完的实体在 `$PREFIX/lib/node_modules/dsh-termux/`，入口是 `lib/bin.js`。

> 直接敲 `dsh` 在安卓上通常起不来，见下一节，必须用包装器。

---

## 3. 放配置

```bash
mkdir -p ~/.dsh/profiles/web ~/dsh-phone ~/tmp
cp config/cordis.patch.yml ~/.dsh/profiles/web/cordis.patch.yml
cp config/dshx.sh config/up.sh ~/dsh-phone/
chmod +x ~/dsh-phone/*.sh
```

### 为什么这些配置非改不可

| 配置 | 不改会怎样 |
|---|---|
| `node --expose-internals` | 安卓缺 `node-addon-require-builtin` 原生绑定，直接崩 |
| `includeHarnessIdentity: false` | 某些兼容端点会因请求里带 "DeepSeek Harness" 字样拒答（返回 11-128 之类的错误） |
| `sandbox-policy.mode: danger-full-access` + `approval.policy: never` | 安卓没有沙箱后端，默认模式一写文件就失败 |
| **模型 ID 手写** | `/v1/models` 返回格式与 dsh 期望不一致（`{models:[...]}` vs `{data:[...]}`），自动拉取为空 |
| 视觉模型写 `input: [text, image]` | 图片被**静默丢弃**，模型只看到文字占位符 |
| `api: openai-completions` | 走 `/v1/responses` 的端点很可能直接 4xx |
| 改完**新建会话** | 沙箱/模型是会话级状态，旧会话不生效 |

---

## 4. 起服务

```bash
bash ~/dsh-phone/up.sh
# 末尾会打印： http://127.0.0.1:3080/?token=xxxxxxxx
```

浏览器打开那条地址即可。

- 后台会话名：`tmux attach -t dsh` 看日志
- 日志：`~/dsh-phone/dsh.log`
- token 每次重启都变，用 `up.sh` 末尾那行，或：
  ```bash
  grep -oE 'http://127.0.0.1:[0-9]+/\?token=[A-Za-z0-9_-]+' ~/dsh-phone/dsh.log | tail -1
  ```

---

## 5. 装能力脚本

```bash
cp scripts/phone/*.sh scripts/phone/*.py ~/dsh-phone/
chmod +x ~/dsh-phone/*.sh
```

验证：

```bash
bash ~/dsh-phone/appctl.sh cur          # 应输出当前前台 App 的包名
bash ~/dsh-phone/ask.sh "只回答两个字：收到"
```

---

## 6. 开机自启（可选）

```bash
mkdir -p ~/.termux/boot
echo 'bash $HOME/dsh-phone/up.sh >> $HOME/dsh-phone/boot.log 2>&1' > ~/.termux/boot/start.sh
chmod +x ~/.termux/boot/start.sh
```

装 **Termux:Boot** 并**手动打开一次**（否则脚本不会执行）。手机重启后 dsh 自动起。

---

## 7. 验收清单

- [ ] `dsh --version` 有输出
- [ ] `bash ~/dsh-phone/up.sh` 打印出 `?token=` 地址
- [ ] 浏览器能打开并对话
- [ ] （若用视觉）发一张图能描述内容，而不是回答"我看不到图片"
- [ ] `bash ~/dsh-phone/appctl.sh text` 能读出屏幕文字
- [ ] `python ~/dsh-phone/quiz.py one "1+1=?" "1" "2"` 能给出答案

任何一项不对 → 看 [09-常见问题](09-常见问题.md)。
