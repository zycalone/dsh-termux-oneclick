# 08 · 能力清单与实测状态

全部来自在一台 Android arm64 真机上的实测，不是"理论上支持"。

## 系统层

| 项 | 状态 | 说明 |
|---|---|---|
| dsh web 界面 | ✅ | `up.sh` 起，`?token=` 地址进浏览器 |
| dsh headless（`ask.sh`） | ✅ | 一句话交任务，适合脚本/cron |
| 开机自启 | ✅ | Termux:Boot + `~/.termux/boot/start.sh` |
| 后台常驻 | ✅ | tmux 会话 `dsh`；`termux-wake-lock` 防休眠 |
| 读写文件 | ✅ | `danger-full-access`，注意风险 |
| `/tmp` 写入 | ❌ | Termux 里不存在，用 `~/tmp` |

## 模型与视觉

| 项 | 状态 | 说明 |
|---|---|---|
| 文本模型 | ✅ | 任何 OpenAI 兼容端点 |
| 视觉模型 | ✅（需声明） | 不声明 `input:[text,image]` 就一定看不到图 |
| 音视频输入 | ❌ | 没有模型支持，只能抽帧读画面 |
| 长上下文 | ⚠️ | 由端点决定；手工填 `defaultContextWindow` 更保险 |

## 手机控制

| 项 | 状态 | 说明 |
|---|---|---|
| 读屏幕控件树 | ✅ | `appctl.sh text`，带坐标和可点标记 |
| 点文字 / 坐标 / 滑动 / 按键 | ✅ | 见 `appctl.sh` |
| 启动任意 App | ✅ | `am start` / `monkey` |
| 截图 | ✅ | `screencap` |
| 微信自动化 | ❌ | uiautomator 只拿到空树（407 字节），只能截图看，无法精确点 |
| 中文输入 | ⚠️ | `input text` 只吃 ASCII；靠 App 内粘贴或用户手输 |
| 跨 App 复制粘贴 | ⚠️ | Android 10+ 剪贴板有前台限制 |

## 文档生成

| 格式 | 状态 | 库 |
|---|---|---|
| .pptx | ✅ | python-pptx |
| .docx | ✅ | python-docx |
| .xlsx | ✅ | openpyxl |
| .pdf | ✅（重排） | reportlab + `UnicodeCIDFont("STSong-Light")` |
| docx→pdf 转换 | ❌ | 无 LibreOffice；用 WPS 导出或 reportlab 重排 |

## 联网与检索

| 项 | 状态 | 说明 |
|---|---|---|
| `web_fetch` 抓网页 | ✅ | 首选 |
| `web_search` | ❌（手机端） | 没有 provider，改抓 `cn.bing.com/search` |
| arXiv / Crossref / PubMed API | ✅ | 返回结构化数据，最可靠 |
| Semantic Scholar | ⚠️ | 会 429 限流，失败就跳过 |
| 知网正文 | ❌ | 需登录，别假装读过 |
