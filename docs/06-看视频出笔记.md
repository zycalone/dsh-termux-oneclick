# 06 · 看视频出笔记

手机上**没有音视频理解模型**，所以做法是：**截画面 → 视觉模型读画面文字 → 文本模型汇总成笔记**。

两条路，都不需要电脑：

| 方式 | 脚本 | 前提 |
|---|---|---|
| 边播边截屏（任何 App） | `screenwatch.py` | 本机 adb 可用 |
| 有视频文件，抽帧 | `vidnote.py` | 装了 `ffmpeg` |

> 两个脚本现在都走 [`llm.py`](12-回退链与反思循环.md) 的回退链：
> 逐帧识图用 `vision_models`，最后汇总用 `models`，某一帧/某个端点挂了不会整段白跑。
> 端点与模型在 `~/dsh-phone/endpoints.json` 里配。

---

## A. 边播边看（推荐，无需下载）

```bash
python ~/dsh-phone/screenwatch.py --minutes 15 --interval 20
```

| 参数 | 含义 | 建议 |
|---|---|---|
| `--minutes` | 总时长（分钟） | 一节网课 15~45 |
| `--interval` | 每几秒截一张 | PPT 型 20；板书快 10 |
| `--max` | 最多帧数（省钱） | 默认 40 |

产物：`~/tmp/vid/live-<月日-时分>/笔记.md`（内容主线 / 概念 / 可能考点 / 逐屏原文）

---

## B. 有视频文件时

```bash
pkg install -y ffmpeg          # 首次，装到 ~/tmp 之外的日志记得别写 /tmp
python ~/dsh-phone/vidnote.py ~/tmp/课.mp4 --interval 30 --max 24
```

抽帧策略：**按画面变化抽**（`select='gt(scene,0.12)'`），PPT 翻页时抓一帧、静止时不重复抓；
画面几乎不变时自动退回等间隔抽帧。

---

## C. 只给链接时（视频解析 → 下载 → 出笔记）

手机上装一次 yt-dlp，之后直接把链接丢给同一个脚本：

```bash
python -m pip install -U yt-dlp                      # 首次（真机装的是 2026.10.26）
python ~/dsh-phone/vidnote.py "https://www.bilibili.com/video/BV18W411U7hS" --max 12 --kind lecture
```

脚本会：**yt-dlp 下载**（`--no-playlist`，取 mp4）→ 落到 `~/tmp/vid/dl/` → 照常抽帧 → 出笔记。

### `--kind` 选产物结构

| `--kind` | 产物 | 什么时候用 |
|---|---|---|
| `note`（默认） | 老格式学习笔记：主线 / 概念 / 可能考点 / 逐屏原文 | 通用 |
| `lecture` | 复用 [minutetool](14-转写稿变笔记.md) 的学习笔记结构（多"易错点""没听懂的部分"） | 讲座、课堂 |
| `meeting` | 复用 minutetool 的会议纪要结构（含**待办表**） | 会议录像 |
| `auto` | 先看内容判断是讲座还是会议，再选上面之一 | 拿不准 |

> 注意：`lecture` / `meeting` 是把**画面文字**当"转写稿"来处理的。没有语音，
> 所以产物只有"屏幕上出现过的字"，不是"谁说了什么"。要完整纪要还是得走
> 云录制转写 + [minutetool](14-转写稿变笔记.md)。

### 真机实测（链接直出）

```

```

而且这次它**没有硬编**——因为抽帧提示词里加了"不要根据标题、推荐栏、搜索词推测视频内容"，
汇总时会老实写成：

```markdown
## 核心概念与定义
- 无。稿中未给出任何术语定义或概念说明。

## 可能考的点和问法
- 无法判断。原稿没有可用于出题的知识点或讲解内容。
```

（早期版本遇到娱乐/纯画面视频会照着标题硬套"学习笔记"框架，这条已经修掉。）

---

## 跑之前的 4 个条件

1. 视频**真的在播放**（不是暂停）。
2. 屏幕**不熄灭**：`adb shell svc power stayon true`，或把息屏时间调长。
3. 过程中**别动手机、别切 App**（切走抓到的就是别的画面）。
4. 手机别过热关机。

---

## 效果预期（说实话）

| 视频类型 | 效果 |
|---|---|
| PPT 型网课（画面文字多） | ✅ 很好，笔记基本能用 |
| 带字幕的口播 | ✅ 不错，字幕会被抄下来 |
| 只有人讲话、无字幕无板书 | ❌ 差，只能知道"在讲课" |
| 公式推导密集 | ⚠️ 一般，把 `--interval` 调小、`--max` 调大 |
| 娱乐/纯画面视频（无文字） | ⚠️ 只能记下画面里出现过的品牌字、字幕；现在会明确说"无可提取文字"，不再硬套框架 |

**更好的替代**：课程若提供 **PPT / PDF / 文字任务点**，直接抓文本，比抽帧准得多也快得多。

---

## 常见问题

- **只出 1~2 帧** → 画面没变化（暂停了/静态页），确认视频在播。
- **报 `ADB_OFFLINE`** → 手机重启过：`bash ~/dsh-phone/fix-adb.sh`。
- **想省钱** → `--interval 40~60`、`--max 15`。
- **帧太大传不上去** → 有 ffmpeg 时会自动压到 720p；没有就 `pkg install ffmpeg`。
- **给链接报 `给链接需要 yt-dlp`** → `python -m pip install -U yt-dlp`。
- **下载失败** → 多半是链接要登录/地区限制；手机端不支持传 cookie，换公开链接或先在别处下好再传进来。
- **下载很慢/很大** → 先在 yt-dlp 里限制清晰度，或直接用本地视频走 B 路线。
