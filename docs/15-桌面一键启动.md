# 15 · 桌面一键启动（不想每次都敲命令）

> 目标：桌面上点一下图标就开工，不用打开 Termux 敲一长串路径。
> 本项目用 **Termux:Widget**（官方小组件）+ **`~/.shortcuts/` 脚本** 实现，另带一个
> **分享链接自动处理** 的钩子和一个 **`m` 菜单** 兜底。

## 1. 装 Termux:Widget（有个签名坑，先看这段）

Termux 的小组件是独立 App `com.termux.widget`，要自己装。

```bash
# 装完确认
adb shell pm list packages | grep termux
# com.termux / com.termux.api / com.termux.boot / com.termux.widget
```

⚠️ **踩过的坑**：F-Droid 版 `com.termux.widget`（`com.termux.widget_13.apk`）装不上，报

```
INSTALL_FAILED_SHARED_USER_INCOMPATIBLE: ... Package com.termux.widget has no signatures
that match those in shared user com.termux
```

原因是这台的 Termux 本体（`0.119.0-beta.3`）是**侧载的 GitHub 版**，签名和 F-Droid 版不一致，
而旧版 widget 声明了 `sharedUserId=com.termux`，必须同签名。

**解决办法**：用 GitHub 的 `v0.15.0`（已去掉 sharedUserId），国内可走加速镜像：

```bash
curl -sSL -o ~/tmp/widget15.apk \
  "https://gh-proxy.com/https://github.com/termux/termux-widget/releases/download/v0.15.0/termux-widget-app_v0.15.0%2Bgithub.debug.apk"
adb install -r ~/tmp/widget15.apk      # Success
```

> 实测：`gh-proxy.com` 通（11 MB，秒下）；`ghfast.top`、`ghproxy.net` 时好时坏；
> PC 直连 `github.com` 超时（WinError 10060），但手机能连（6.5s）。

装好后必须打开外部执行开关，否则点了没反应：

```bash
echo 'allow-external-apps = true' >> ~/.termux/termux.properties
termux-reload-settings
```

## 2. 脚本放哪：前台 vs 后台

| 目录 | 行为 | 适合 |
|---|---|---|
| `~/.shortcuts/*.sh` | 点一下**打开终端窗口**执行 | 要看着跑、要 Ctrl+C 停的（开会记纪要） |
| `~/.shortcuts/tasks/*.sh` | **后台静默**执行，不弹窗 | 修 adb、定时收集这类不需要看的 |

## 3. 已经配好的 6 个图标

| 图标 | 干什么 |
|---|---|
| **开会记纪要** | `meetnote.py --interval 15 --keep-awake`，全程记屏，Ctrl+C 出纪要 |
| **看屏幕做笔记** | `screenwatch.py --minutes 20`，边看边记 |
| **解析手机上最新视频** | 自动找 `/sdcard/Download`+相册里**最新的视频**，抽帧出笔记 |
| **最新转写稿成笔记** | 自动找下载目录里**最新的 txt/md/srt/docx/pdf**，出纪要或学习笔记 |
| **修ADB连接** | `fix-adb.sh`，拔线/重启后 adb 连不上时点 |
| **看看状态** | `healthcheck.sh`，adb / 网关 / 模型 自检 |

后台任务：**修ADB后台**（静默修复，日志写 `~/dsh-phone/fixadb-后台.log`）。

> 「最新视频 / 最新转写稿」这两个是故意的设计：你不用敲路径，
> 把文件丢进**下载**目录，点图标就处理最新的那个。

## 4. 怎么放到桌面上（vivo / 一般安卓都差不多）

**方式 A：小组件（一次拖一个，之后点列表里的名字）**

1. 长按桌面空白处 → **小组件 / 窗口小工具**
2. 找到 **Termux:Widget** → 拖到桌面
3. 点它 → 弹出脚本列表 → 点「开会记纪要」就跑

**方式 B：单个图标（更像原生 App，推荐）**

1. 长按桌面空白处 → **快捷方式 / 添加工具**
2. 选 **Termux:Widget**
3. 选一个脚本 → 桌面上就出现一个独立图标，名字就是脚本名

> ⚠️ 第一次点图标，系统可能弹「Termux:Widget 请求权限 `com.termux.permission.RUN_COMMAND`」，
> 选**允许**（这是 Termux 放行外部调用的门禁，只在本机有效）。
> 不给权限的话点了没反应。

## 5. 连链接都不用复制：分享到 Termux

配了 `~/bin/termux-url-opener`，所以在 B站/浏览器里：

```
视频页 → 分享 → Termux   →  自动下载 + 抽帧 + 出笔记
```

脚本内容（已就位）：

```bash
#!/data/data/com.termux/files/usr/bin/bash
url="$1"
python "$HOME/dsh-phone/vidnote.py" "$url" --max 16 --kind auto
```

日志：`~/dsh-phone/链接解析日志.txt`

## 6. 兜底：`m` 菜单

万一小组件被系统杀了/权限没给，还有一条路——打开 Termux 敲 `m`：

```
========= dsh 手机端 一键菜单 =========
  1) 开会记纪要
  2) 看屏幕做笔记
  3) 解析手机上最新视频
  4) 最新转写稿成笔记
  5) 修 ADB 连接
  6) 看看状态
  7) 打开 dsh 网页版
  0) 退出
```

（已在 `~/.bashrc` 里加了 `alias m='bash ~/dsh-phone/menu.sh'`）

## 8. 想加自己的图标

往 `~/.shortcuts/` 扔一个可执行的 `.sh` 就行，脚本名就是图标名：

```bash
cat > ~/.shortcuts/我的任务.sh <<'EOS'
#!/data/data/com.termux/files/usr/bin/bash
python ~/dsh-phone/xxx.py
read -r _     # 加这一行，跑完停住，好看结果
EOS
chmod +x ~/.shortcuts/我的任务.sh
```
