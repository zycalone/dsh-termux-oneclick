# 09 · 常见问题

## 起不来

**`dsh` 直接运行就崩**
安卓缺 `node-addon-require-builtin` 原生绑定。必须：
```bash
node --expose-internals "$(readlink -f $PREFIX/bin/dsh)" web
```
即用 `dshx.sh`。

**页面 404 / 打不开**
1. `tmux attach -t dsh` 看有没有报错
2. token 变了：`grep -oE 'http://127.0.0.1:[0-9]+/\?token=[A-Za-z0-9_-]+' ~/dsh-phone/dsh.log | tail -1`
3. 端口被占：换个端口起

**模型列表是空的**
兼容端点的 `/v1/models` 格式与 dsh 期望不一致。**手写模型清单**，别开自动获取。

**所有请求 4xx，但地址和 key 都对**
- 打开 `api: openai-completions`（别用 responses）
- 某些端点不认 `developer` 角色 → `compat.supportsDeveloperRole: false`
- 某些端点要 `max_tokens` 而不是 `max_completion_tokens` → `maxTokensField: max_tokens`
- 关闭 `includeHarnessIdentity`（请求里带 "DeepSeek Harness" 可能被拒）

## 视觉相关

**模型说看不见图片**
视觉模型没声明 `input: [text, image]`。见 [04-识图](04-识图.md)。

**小字看不清**
先 2× 放大再送，或裁到目标区域。JPEG 质量别太低。

## 手机控制

**`appctl.sh` 报 `ADB_OFFLINE` / `device not found`**
手机重启过：`bash ~/dsh-phone/fix-adb.sh`。仍不行就关掉再打开「无线调试」，端口可能变了。

**adb 命令敲了没反应**
从脚本里调要加 `</dev/null`。

**`uiautomator dump` 只返回几百字节**
该 App 加固/自绘，拿不到控件树（微信就是这样）。只能截图让人看，别硬刚。

**中文打不进去**
`input text` 只支持 ASCII。用英文/拼音、App 内粘贴，或让用户自己输。

## 文件

**`adb pull` 中文文件名失败**
`adb exec-out cat > 文件名`，或先 `adb shell cp` 到 `/sdcard/Download/`。

**写完脚本一跑就报 `bad interpreter`**
CRLF 没去掉：`sed -i 's/\r$//' 脚本.sh`。

**`/tmp` 不可写**
Termux 里就没有 `/tmp`，用 `~/tmp`，并把 `TMPDIR=~/tmp`。

## 效率与成本

**抽帧太贵**
`--interval` 调大、`--max` 调小；先让视觉模型只做 OCR，再让便宜模型总结。

**`pkg install` 卡在某个包**
换镜像：`termux-change-repo`，再重跑。别在 `/tmp` 写安装日志。
